## AudioSource {id="audio-source",tag="class"}

描述尚未解码的音频来源。来源可以是文件路径、URL、ModelScope 数据集文件、编码字节、
base64 字符串或 PCM S16LE 字节。`load()` 解码为完整 [`Audio`](#audio)，`stream()`
创建逐块解码的 [`AudioStream`](#audio-stream)。

## AudioSource.from\_\* {id="audio-source-from",tag="class methods"}

从路径、URL、ModelScope 文件、编码字节、base64 或 PCM 创建尚未解码的音频来源。构造时
通常不会读取文件、发起网络请求或解码样本；真正的 I/O 发生在 `probe()`、`load()` 或
`stream()` 时。`from_modelscope()` 只保存仓库 ID、文件路径和 revision。探测或加载时
由 modelhub 只下载这一个 ModelScope 数据集文件；缓存里已有该文件时不再访问网络。
`from_pcm()` 没有文件头，因此必须显式提供 `sample_rate`
和 `channels`。

> #### Example
>
> ```python
> import base64
> from pathlib import Path
> from tempfile import TemporaryDirectory
> from urllib.request import urlopen, urlretrieve
>
> import numpy as np
>
> from asr_data import AudioSource, Waveform
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
>
> with TemporaryDirectory() as directory:
>     path = Path(directory) / "example.wav"
>     urlretrieve(URL, path)
>     from_path = AudioSource.from_path(str(path))
>
> from_url = AudioSource.from_url(URL)
> with urlopen(URL) as response:
>     audio_bytes = response.read()
> from_bytes = AudioSource.from_bytes(audio_bytes)
> from_base64 = AudioSource.from_base64(base64.b64encode(audio_bytes).decode("ascii"))
>
> waveform = Waveform.from_url(URL).to_mono().resample(16_000)
> pcm_bytes = (np.clip(waveform.samples, -1.0, 1.0) * 32_767).astype("<i2").tobytes()
> from_pcm = AudioSource.from_pcm(pcm_bytes, sample_rate=16_000, channels=1)
>
> for source in (from_path, from_url, from_bytes, from_base64, from_pcm):
>     audio = source.load()
>     print(source.kind, audio.info.sample_rate, audio.info.channels)
> ```

| Method | Input |
| --- | --- |
| `from_path(path)` | 本地音频文件路径。~~str~~ |
| `from_url(url)` | HTTP 或 HTTPS 音频地址。~~str~~ |
| `from_modelscope(repo_id, file_path, *, revision=None)` | ModelScope 数据集中的单个音频文件。~~str, str, Optional[str]~~ |
| `from_bytes(data)` | WAV、MP3 等编码音频字节。~~bytes~~ |
| `from_base64(data)` | base64 编码的音频内容。~~str~~ |
| `from_pcm(data, sample_rate, channels=1)` | PCM S16LE 字节。~~bytes, int, int~~ |

所有方法均返回新的 [`AudioSource`](#audio-source)。

## AudioSource.load {id="audio-source-load",tag="method"}

完整读取并解码来源，创建带波形、音频信息和各声道时间轴的 [`Audio`](#audio)。
接受可选的关键字参数 `id`。

> #### Example
>
> ```python
> from asr_data import AudioSource
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
> source = AudioSource.from_url(URL)
> audio = source.load(id="example-001")
> print(audio.id, audio.info.duration_ms)
> waveform = audio.as_waveform().to_mono().resample(16_000)
> print(waveform.sample_rate, waveform.channels)
> ```

| Name           | Description                    |
| -------------- | ------------------------------ |
| _keyword-only_ |                                |
| `id`           | 可选的文档 ID。~~Optional[str]~~ |
| **RETURNS**    | 中心音频对象。~~Audio~~        |

异步程序使用 `await source.aload(...)`。

## AudioSource.stream {id="audio-source-stream",tag="method"}

创建与 [`Audio`](#audio) 同级的 [`AudioStream`](#audio-stream)，按固定目标时长
逐块解码。创建流时只探测格式，不读取完整波形。

> #### Example
>
> ```python
> from asr_data import AudioSource
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
> stream = AudioSource.from_url(URL).stream(chunk_size_ms=100, id="call-001")
>
> for chunk in stream:
>     print(chunk.offset_ms, stream.position_ms, stream.timeline("mono").duration_ms)
>
> audio = stream.to_audio()
> ```

| Name            | Description                                        |
| --------------- | -------------------------------------------------- |
| `chunk_size_ms` | 每块的目标时长，默认为 `100`。~~int~~              |
| _keyword-only_  |                                                    |
| `id`            | 可选的文档 ID。~~Optional[str]~~                   |
| **RETURNS**     | 可同步或异步消费的音频流。~~AudioStream~~          |

同一个 `AudioStream` 可以使用普通 `for` 或 `async for`，但一次流实例不能混合同步与
异步消费。

## AudioStream {id="audio-stream",tag="class"}

逐步增长的流式音频文档，由 [`AudioSource.stream()`](#audio-source-stream) 创建。
它与 [`Audio`](#audio) 处于同一层级，提供相同的 `id`、`source`、`info`、
`metadata`、`timelines`、`timeline()` 和 `as_waveform()` 访问方式；区别是波形和
时间轴只覆盖已经迭代到的音频。

每次取得 [`AudioChunk`](#audio-chunk) 前，该块会先追加到流中。因此模型处理当前
chunk 时，可以读取包括当前块在内的累计波形，并给任意已接收历史范围添加标注；
超过 `position_ms` 的未来范围会被拒绝。

`AudioStream` 提供与 [`AudioSource`](#audio-source) 对称的便捷构造器，默认
`chunk_size_ms=100`，都接受 keyword-only 的可选 `id`：

| Method | Input |
| --- | --- |
| `from_path(path, ...)` | 本地文件路径 |
| `from_url(url, ...)` | HTTP、HTTPS 或 file URL |
| `from_modelscope(repo_id, file_path, ...)` | ModelScope 数据集中的单个音频文件 |
| `from_bytes(data, ...)` | WAV、MP3 等编码音频字节 |
| `from_base64(data, ...)` | 编码音频的 base64 字符串 |
| `from_pcm(data, sample_rate, channels=1, ...)` | PCM S16LE 原始字节 |

> #### Example
>
> ```python
> from asr_data import AudioStream
> from asr_data.annotation import Speech, Transcription
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
> stream = AudioStream.from_url(URL, chunk_size_ms=1_000, id="call-001")
>
> for chunk in stream:
>     timeline = chunk.timeline("mono")
>     print(stream.position_ms, timeline.duration_ms)
>
>     timeline.annotate(
>         0,
>         timeline.duration_ms,
>         Speech(transcription=Transcription("甚至出现交易几乎停滞的情况")),
>         is_reference=True,
>     )
> audio = stream.to_audio()
> ```

| Name            | Description                                                   |
| --------------- | ------------------------------------------------------------- |
| `position_ms`   | 当前已接收音频的结束位置。~~int~~                             |
| `is_complete`   | 是否已消费到来源结尾。~~bool~~                                |
| `is_closed`     | 是否已经关闭。~~bool~~                                        |
| `as_waveform()` | 返回当前累计波形。~~Waveform~~                                |
| `display(...)`  | 在 Jupyter 中播放当前累计波形。~~None~~                       |
| `timeline()`    | 返回指定声道的增长中时间轴。~~Optional[Timeline]~~            |
| `to_audio()`    | 完整消费后零重复解码地转换为 `Audio`。~~Audio~~               |
| `close()`       | 关闭流；关闭后不能继续迭代或转换。~~None~~                    |

`async for chunk in stream` 使用同一组属性和方法。一个实例一旦开始同步或异步消费，
后续就必须保持该模式。`to_audio()` 只接受完整流，并保留累计波形、时间轴、标注和
metadata。

## AudioChunk {id="audio-chunk",tag="class"}

流式解码产生的当前局部音频块。它与父 [`AudioStream`](#audio-stream) 共享文档
`id`、`source`、可修改 `metadata` 和全局 `timelines`，但 `info` 与
`as_waveform()` 只描述当前块。旧 chunk 的局部波形保持不变，共享 timeline 则会随
流继续增长。

| Name          | Description                                                |
| ------------- | ---------------------------------------------------------- |
| `id`          | 与父 AudioStream 相同的文档 ID。~~str~~                    |
| `source`      | 与父 AudioStream 相同的 AudioSource。~~AudioSource~~       |
| `info`        | 只描述当前块的音频信息。~~AudioInfo~~                      |
| `metadata`    | 与父 AudioStream 共享的字典。~~Dict[str, JsonValue]~~      |
| `timelines`   | 与父 AudioStream 共享的全局时间轴。~~Dict[str, Timeline]~~ |
| `index`       | 当前块从零开始的流内序号。~~int~~                          |
| `offset_ms`   | 当前块相对原音频的起始偏移。~~int~~                        |
| `end_ms`      | 当前块在完整音频中的结束位置。~~int~~                      |
| `duration_ms` | 当前块时长。~~float~~                                      |
| `is_final`    | 是否为流中的最后一块。~~bool~~                             |

`as_waveform(channel=None)` 返回当前块的波形；`timeline(channel)` 返回父
[`AudioStream`](#audio-stream) 当前增长到的全局时间轴；
`to_timeline_range(start_ms, end_ms)` 把块内相对范围转换为共享时间轴中的全局范围。
`display(start_ms=None, end_ms=None, autoplay=False)` 直接播放当前 chunk，时间参数
使用 chunk 内的局部坐标。波形变换统一通过 `chunk.as_waveform()` 返回的
[`Waveform`](#waveform) 完成。

## Audio {id="audio",tag="class"}

完整音频、时间轴与标注的中心对象。它包含文档 ID、[`AudioSource`](#audio-source)、
[`AudioInfo`](#audio-info)、业务元数据、各声道 [`Timeline`](#timeline) 和完整
运行时 [`Waveform`](#waveform)。数据库不会持久化浮点样本。

## Audio.\_\_init\_\_ {id="audio-init",tag="method"}

从来源创建完整音频记录。构造时加载波形、保存 `info`，并自动创建全部原始声道的
timeline。通常优先使用 [`AudioSource.load()`](#audio-source-load)。


| Name     | Description                                    |
| -------- | ---------------------------------------------- |
| `source` | 音频来源。~~AudioSource~~                      |
| `id`     | 文档 ID；省略时自动生成。~~Optional[str]~~ |

单声道创建 `mono`；双声道创建 `left` 和 `right`；更多声道继续以 `2`、`3` 等
编号。每条 timeline 的整数毫秒时长由 `info` 向上取整得到。异步程序使用
`await source.aload(id=...)`。

## Audio.from_\* {id="audio-from",tag="static methods"}

不需要先显式创建 [`AudioSource`](#audio-source) 的便捷构造器。所有方法完整解码
音频并自动创建各声道 timeline，且都接受 keyword-only 的可选 `id`。

> #### Example
>
> ```python
> from asr_data import Audio
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
> audio = Audio.from_url(URL, id="call-001")
> print(audio.id, audio.info.duration_ms)
> ```

| Method | Input |
| --- | --- |
| `from_path(path, *, id=None)` | 本地文件路径 |
| `from_url(url, *, id=None)` | HTTP、HTTPS 或 file URL |
| `from_modelscope(repo_id, file_path, *, revision=None, id=None)` | ModelScope 数据集中的单个音频文件 |
| `from_bytes(data, *, id=None)` | WAV、MP3 等编码音频字节 |
| `from_base64(data, *, id=None)` | 编码音频的 base64 字符串 |
| `from_pcm(data, sample_rate, channels=1, *, id=None)` | PCM S16LE 原始字节 |

## Audio.remove_timeline {id="audio-remove-timeline",tag="method"}

| Name        | Description                         |
| ----------- | ----------------------------------- |

## Timeline {id="timeline",tag="class"}

某个声道上的时间轴。参考真值保存在 `reference`，模型预测保存在 `prediction`，两者
都是 [`AudioEvent`](#audio-event) 列表，其中语音是 [`Speech`](#speech)。

| Name          | Description                                                        |
| ------------- | ------------------------------------------------------------------ |
| `id`          | Timeline 唯一 ID。~~str~~                                          |
| `audio_id`    | 所属 Audio ID，可修改。~~str~~                                     |
| `duration_ms` | Timeline 总时长。~~int~~                                           |
| `reference`   | 参考事件列表。语音是 `Speech`，其余是 `AudioEvent`。~~List[AudioEvent]~~ |
| `prediction`  | 预测事件列表，每条都带非空 `source`。~~List[AudioEvent]~~          |

`as_waveform()` 返回该声道的完整波形；`display()` 可直接播放该声道的全部或部分音频。
写入事件用 [`Timeline.annotate()`](#timeline-annotate)，删除单条事件用
[`Timeline.remove()`](#timeline-remove)。参考转写由 `reference_transcript` 提供；
预测来源的转写、删除与改名分别由
[`prediction_transcript()`](#timeline-prediction-transcript)、
[`remove_predictions()`](#timeline-remove-predictions) 和
[`relabel_prediction_source()`](#timeline-relabel-prediction-source) 提供。

语音额外暴露 `language`、`speaker` 和 `transcription`，不再有独立的包裹对象，也没有
`transcriptions`、`activities`、`speakers` 这类顶层便捷属性。

>
> ```python
> from asr_data import AudioSource
> from asr_data.annotation import Speech, Transcription
>

> timeline = AudioSource.from_url(URL).load().timeline("mono")
> timeline.annotate(
>     0,
>     timeline.duration_ms,
>     Speech(transcription=Transcription("甚至出现交易几乎停滞的情况")),

> )
>
> for event in timeline.reference:
>     print(event.id, event.start_ms, event.end_ms, event.name)
>
> for event in timeline.prediction:
>     print(event.source, event.name)
> ```

## Timeline.eval {id="timeline-eval",tag="method"}

使用 reference 评估 prediction。不传 source 时自动评测全部可用来源；也可以为转写
和 Activity 分别指定一个或多个来源。转写默认先执行内嵌中文 TN，再计算 CER。

> #### Example
>
> ```python
> from asr_data import AudioSource
> from asr_data.annotation import Speech, Transcription
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
> doc = AudioSource.from_url(URL).load()
> timeline = doc.timeline("mono")
> text = "甚至出现交易几乎停滞的情况"
>
> timeline.annotate(
>     0,
>     timeline.duration_ms,
>     Speech(language="zh", transcription=Transcription(text)),
>     is_reference=True,
> )
> timeline.annotate(
>     0, timeline.duration_ms, Speech(), is_reference=False, source="silero-vad"
> )
> timeline.annotate(
>     0,
>     timeline.duration_ms,
>     Speech(language="zh", transcription=Transcription(text)),
>     is_reference=False,
>     source="qwen-asr",
> )
>
> result = timeline.eval()
> print(
>     result.transcription["qwen-asr"].cer,
>     result.activity["silero-vad"].f1,
> )
> ```

| --------------- | ------------------------------------------------------------- |
| _keyword-only_  |                                                               |
| `transcription` | 转写来源或来源列表；省略时自动发现。~~Optional[str \| List[str]]~~ |
| `activity`      | Activity 来源或来源列表；省略时自动发现。~~Optional[str \| List[str]]~~ |

## Timeline.reference {id="timeline-reference",tag="property"}

参考真值事件列表，元素是 [`AudioEvent`](#audio-event)，其中语音是 [`Speech`](#speech)。
Reference 事件的 `source` 始终为 `None`。相同 `name` 的非语音事件不得重叠；两段语音
只有在双方都有说话人且名字不同时才允许重叠；时间范围采用 `[start_ms, end_ms)`，首尾
相接不算重叠。完整规则见
[标注校验规范](/asr-data/annotations#validation)。

> #### Example
>
> ```python
> from asr_data import AudioSource

> timeline = AudioSource.from_url(URL).load().timeline("mono")
> timeline.annotate(0, timeline.duration_ms, Speech())
>
> for event in timeline.reference:
>     print(event.id, event.start_ms, event.end_ms, event.name)
> ```

| Name        | Description                        |
| ----------- | ---------------------------------- |
| **RETURNS** | 参考事件列表。~~List[AudioEvent]~~ |

需要筛选时直接在 Python 侧遍历 `timeline.reference` 并按事件属性过滤；不存在独立的
`spans` 集合对象。

## Timeline.annotate {id="timeline-annotate",tag="method"}

Timeline 唯一的标注写入口。`is_reference=True` 写入参考答案，此时必须省略
`source`；`is_reference=False` 写入模型预测，此时必须提供非空 `source`。第三个参数
接受 [`AudioEvent`](#audio-event) 或派生的 [`Speech`](#speech)，不接受纯字符串。
时间范围必须满足 `0 <= start_ms` 且 `start_ms < end_ms <= timeline.duration_ms`。

> #### Example
>
> ```python
> from asr_data import Audio
> from asr_data.annotation import AudioEvent, Speech, Speaker, Transcription
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
> timeline = Audio.from_url(URL).timeline("mono")
>
> music = timeline.annotate(
>     0, timeline.duration_ms, AudioEvent("music", confidence=0.98), is_reference=True
> )
> speech = timeline.annotate(
>     0,
>     timeline.duration_ms,
>     Speech(
>         language="zh",
>         speaker=Speaker("agent", gender="female"),
>         transcription=Transcription("甚至出现交易几乎停滞的情况"),
>     ),
>     is_reference=False,
>     source="diarization-v2",
> )
> print(music.name, speech.source, speech.speaker.name)
> ```

| Name             | Description                                                       |
| ---------------- | ----------------------------------------------------------------- |
| `start_ms`       | 起始时间，`0 <= start_ms`。~~int~~                                |
| `end_ms`         | 结束时间，`start_ms < end_ms <= duration_ms`。~~int~~             |
| `event`          | 基类事件或语音事件。~~AudioEvent~~                                |
| _keyword-only_   |                                                                   |
| `is_reference`   | 是否写入参考答案，默认为 `True`。~~bool~~                         |
| `source`         | Prediction 的模型或流程；reference 必须省略。~~Optional[str]~~    |
| **RETURNS**      | 写入后的事件；语音返回 `Speech`。~~AudioEvent~~                   |

返回值是写入后事件的副本，不是可回写的活动句柄；需要改内容时先
[`Timeline.remove()`](#timeline-remove) 再重新写入，或对预测来源使用
[`relabel_prediction_source()`](#timeline-relabel-prediction-source)。带时间范围的
token 必须完全位于所属 [`Speech`](#speech) 的范围内。

## Speech {id="speech",tag="class"}

从 [`AudioEvent`](#audio-event) 派生的语音事件，事件名固定为 `"speech"`。语种、
说话人和转写都可以缺，因此只有活动区间的 VAD 结果也是一条合法语音。一段语音最多挂

> #### Example
>
> ```python
> from asr_data.annotation import Sentence, Speech, Speaker, Token, Transcription
>
> speech = Speech(
>     language="zh",
>     speaker=Speaker("agent", gender="female"),
>     transcription=Transcription(
>         "甚至出现交易几乎停滞的情况",
>         sentences=[
>             Sentence(
>                 "甚至出现交易几乎停滞的情况",
>                 0,
>                 3_000,
>                 tokens=[Token("甚至出现", start_ms=0, end_ms=1_000)],
>             )
>         ],
>     ),
>     confidence=0.97,
> )
> print(speech.name, speech.language, speech.speaker.name)
> ```

| Name            | Description                             |
| --------------- | --------------------------------------- |
| `language`      | 可选 BCP-47 语种标签。~~Optional[str]~~ |
| `speaker`       | 可选说话人。~~Optional[Speaker]~~       |
| `transcription` | 可选转写。~~Optional[Transcription]~~   |
| `confidence`    | 可选活动检测置信度。~~Optional[float]~~ |

`Speech` 继承 [`AudioEvent`](#audio-event) 的 `id`、`name`、`start_ms`、`end_ms`、
`source` 和 `confidence`，并额外提供 `language`、`speaker` 和 `transcription`。
句子时间必须落在语音范围内，token 时间必须落在句子范围内。

>         Sentence(
>             "甚至出现交易几乎停滞的情况",
>             0,
>             3_000,
>             tokens=[Token("甚至出现", start_ms=0, end_ms=1_000)],

| Name           | Description                                            |
| -------------- | ------------------------------------------------------ |

| _keyword-only_ |                                                        |

## AudioDB.query {id="audio-db-query",tag="method"}

> from datetime import datetime, timedelta, timezone
> from pathlib import Path

| Name              | Description                                          |
| ----------------- | ---------------------------------------------------- |

| `after`           | 上一页最后一条 audio ID。~~Optional[str]~~           |
| `min_duration_ms` | 可选最短时长。~~Optional[int]~~                      |

## AudioDB.eval_activity {id="audio-db-eval-activity",tag="method"}

## AudioDB.eval_speaker {id="audio-db-eval-speaker",tag="method"}

使用标签无关的最佳映射评测 Speaker，并直接返回以 prediction source 为键的
[`DatasetSpeakerEvaluation`](#dataset-speaker-evaluation) 字典：

```python
speaker = db.eval_speaker("diarizer", metadata={"split": "test"})
```

DER 不使用 collar。重叠说话按 speaker-time 计数；每条 timeline 独立求最佳映射，
再在数据库级累计漏检、误检和说话人混淆时长。

## AudioDB mapping protocol {id="audio-db-protocol",tag="methods"}

数据库支持 Python 映射式访问。

> #### Example
>
> ```python
> from pathlib import Path
> from tempfile import TemporaryDirectory
>
> from asr_data import AudioDB, Audio, AudioSource
>
> URL = "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav"
>
> with TemporaryDirectory() as directory:
>     path = Path(directory) / "dataset.db"
>     db = AudioDB.create(str(path))
>     db.insert(AudioSource.from_url(URL).load(id="call-001"))
>
>     loaded = db["call-001"]
>     print(loaded.id, "call-001" in db, len(db))
>     print([doc.id for doc in db])
> ```

| API              | Description                            |
| ---------------- | -------------------------------------- |
| `db[audio_id]`   | 按 ID 获取记录。~~Audio~~           |
| `audio_id in db` | 检查 ID 是否存在。~~bool~~             |
| `len(db)`        | 数据库记录数。~~int~~                  |
| `iter(db)`       | 懒加载全部记录。~~Iterator[Audio]~~ |

## AsrDataError {id="asr-data-error",tag="exception"}

`asr-data` 数据校验、音频处理和数据库操作使用的公共异常类型。

> #### Python Example
>
> ```python
> from asr_data import AsrDataError, AudioSource
>
> try:
>     AudioSource.from_bytes(b"not audio").load()
> except AsrDataError as error:
>     print(error)
> ```

> #### Rust Example
>
> ```rust
> use asr_data::AudioSource;
>
> let result = AudioSource::from_encoded_bytes(b"not audio".to_vec()).load();
> if let Err(error) = result {
>     eprintln!("{error}");
> }
> ```

按 ID 读取不存在的数据库记录时使用 Python 标准 `KeyError`。

## normalize_zh {id="normalize-zh",tag="function"}

使用内嵌的中文 TN 规则，把书写形式转换为适合 ASR 比较的口语形式。FST 资源随
`asr-data` 一起提供，不需要调用外部服务。

> #### Example
>
> ```python
> from asr_data import normalize_zh
>
> text = normalize_zh("2024年")
> print(text)  # 二零二四年
> ```

| Name                    | Description                                      |
| ----------------------- | ------------------------------------------------ |
| `text`                  | 需要归一化的中文文本。~~str~~                    |
| `traditional_to_simple` | 是否繁转简，默认为 `True`。~~bool~~              |
| `full_to_half`          | 是否全角转半角，默认为 `True`。~~bool~~          |
| `remove_erhua`          | 是否去除儿化音“儿”，默认为 `True`。~~bool~~      |
| `remove_interjections`  | 是否去除语气词，默认为 `True`。~~bool~~          |
| `remove_puncts`         | 是否去除标点，默认为 `True`。~~bool~~            |
| **RETURNS**             | 归一化后的文本。~~str~~                          |

处理失败时抛出 [`AsrDataError`](#asr-data-error)。
