`asr-data` 是一个 Rust 核心、Python 绑定的 ASR 数据管理库。它以
[`Audio`](/asr-data/api#audio) 为中心，统一组织音频来源、按声道时间轴、参考标注
与模型预测，并通过 SQLite 完成持久化、查询和数据集评测。

源码：[di-osc/asr-data](https://github.com/di-osc/asr-data)

## 安装 {id="installation"}

Python 需要 3.10 或更高版本。PyPI wheel 已包含 Rust 扩展，并提供类型存根与
`py.typed` 标记：

```bash
pip install asr-data
```

Rust 项目可以直接添加 crate：

```bash
cargo add asr-data
```

> #### Python Example
>
> ```python
> from asr_data import AudioSource
>
> source = AudioSource.from_path("audio.wav")
> print(source.kind)
> ```

> #### Rust Example
>
> ```rust
> use asr_data::AudioSource;
>
> fn main() {
>     let source = AudioSource::from_path("audio.wav");
>     println!("{source:?}");
> }
> ```

## 核心概念 {id="concepts"}

<Image
  src="/asr-data/architecture.svg"
  alt="asr-data 从 AudioSource 到 Audio、Waveform、AudioStream、Timeline 与 TimeSpan 的数据模型关系图"
  width="1200"
/>

- **音频来源**：[`AudioSource`](/asr-data/api#audio-source) 统一表达 Path、URL、
  Bytes、Base64 和 PCM。`probe()` 只读取格式信息，`load()` 完整加载音频，
  `stream()` 则按块读取。
- **音频与波形**：[`Audio`](/asr-data/api#audio) 保存来源、格式、ID、metadata 和
  各声道 timeline；[`Waveform`](/asr-data/api#waveform) 提供重采样、声道转换和
  时间切片等操作。
- **时间轴与标注**：声道是 `Audio.timelines` 映射的 key；每条
  [`Timeline`](/asr-data/api#timeline) 保存时长，并将标注分为不带 `source` 的
  reference 和必须带 `source` 的 prediction。
- **持久化**：[`AudioDB`](/asr-data/api#audio-db) 保存 Audio 的来源、格式、
  metadata、timeline 和标注。解码后的浮点波形不会写入数据库，读取后仍可按来源加载。
- **数据集与评测**：[`AudioDataset`](/asr-data/api#audio-dataset) 组织可选的
  train、val、test 数据库；评测 API 支持转写、声音活动和说话人分离任务。

以下示例假设 `audio.wav` 是单声道音频，因此可以直接读取 `mono` timeline。多声道音频
应使用 `left`、`right` 或具体声道索引，详见[音频指南](/asr-data/audio)。

> #### Python Example
>
> ```python
> from asr_data import AudioSource
>
> audio = AudioSource.from_path("audio.wav").load(id="sample-001")
> waveform = audio.as_waveform().to_mono().resample(16_000)
> timeline = audio.timeline("mono")
>
> print(waveform.sample_rate, timeline.duration_ms)
> ```

> #### Rust Example
>
> ```rust
> use asr_data::{Audio, AudioChannel};
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let mut audio = Audio::from_path("audio.wav")?;
>     let waveform = audio.as_waveform()?.to_mono()?.resample(16_000)?;
>     let timeline = audio.timeline(AudioChannel::Mono)?.unwrap();
>
>     println!("{} {}", waveform.sample_rate, timeline.duration_ms());
>     Ok(())
> }
> ```

## 快速开始 {id="quickstart"}

典型流程是：加载音频、取得对应声道的 timeline、添加 reference 或 prediction 标注，
最后将完整 `Audio` 写入 SQLite。prediction 必须使用 `source` 标识模型或版本；reference
不能设置 `source`。

下面只展示最小流程，并继续使用单声道的 `audio.wav`。音频输入、流式处理、标注校验、
数据库查询和评测的完整说明请继续阅读[音频](/asr-data/audio)、[标注](/asr-data/annotations)与
[数据库](/asr-data/database)章节。

> #### Python Example
>
> ```python
> from asr_data import AudioDB, AudioSource
> from asr_data.annotation import Transcription
>
> audio = AudioSource.from_path("audio.wav").load(id="sample-001")
> timeline = audio.timeline("mono")
> timeline.annotate_span(
>     0,
>     timeline.duration_ms,
>     Transcription("识别结果", language="zh"),
>     is_reference=False,
>     source="my-asr",
> )
>
> db = AudioDB.create("dataset.db")
> db.insert(audio)
> ```

> #### Rust Example
>
> ```rust
> use asr_data::{Audio, AudioChannel, AudioDb, Transcription};
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let mut audio = Audio::from_path("audio.wav")?;
>     let end = audio.info.timeline_duration_ms();
>     let timeline = audio.timeline_mut(AudioChannel::Mono)?.unwrap();
>     timeline.annotate_span_with(0, end, Transcription::new("识别结果"), false, Some("my-asr"))?;
>
>     let db = AudioDb::create("dataset.db")?;
>     db.insert(&audio)?;
>     Ok(())
> }
> ```

<Infobox title="时间单位">

Timeline 时长和 annotation 范围均使用毫秒。时间范围采用左闭右开区间，并且必须包含在
当前 timeline 的有效范围内。

</Infobox>
