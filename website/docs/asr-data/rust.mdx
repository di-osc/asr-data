## AudioSource {id="audio-source",tag="enum"}

描述尚未解码的音频来源。它是一个 enum，因此来源类型在编译期明确，不依赖字符串
kind。`load()` 解码为完整 [`Audio`](#audio)，`stream()` 创建逐块解码的
[`AudioStream`](#audio-stream)。

| Variant                                     | Description           |
| ------------------------------------------- | --------------------- |
| `Path(PathBuf)`                             | 本地音频文件。        |
| `Url(String)`                               | HTTP 或 HTTPS 地址。  |
| `ModelScope { repo_id, file_path, revision }` | ModelScope 数据集中的单个文件。 |
| `EncodedBytes(Vec<u8>)`                     | WAV、MP3 等编码字节。 |
| `Base64(String)`                            | base64 编码的音频。   |
| `PcmS16Le { bytes, sample_rate, channels }` | PCM S16LE 音频。      |

## AudioSource::from_url {id="audio-source-from-url",tag="associated function"}

从 URL 创建音频来源。构造过程不发起请求，调用 `load()` 时才下载并解码。

> #### Example
>
> ```rust
> use asr_data::AudioSource;
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let source = AudioSource::from_url(URL);
>     let audio = source.load()?;
>     println!("{:.0} ms", audio.info.duration_ms());
>     Ok(())
> }
> ```

| Name        | Description                                           |
| ----------- | ----------------------------------------------------- |
| `url`       | 可转换为 `String` 的 URL。~~impl Into&lt;String&gt;~~ |
| **RETURNS** | 尚未加载的来源。~~AudioSource~~                       |

## AudioSource constructors {id="audio-source-constructors",tag="associated functions"}

其他构造方法直接对应 enum 的其余来源形式。

| Method                                         | Description                |
| ---------------------------------------------- | -------------------------- |
| `from_path(path)`                              | 从本地路径创建来源。       |
| `from_modelscope(repo_id, file_path, revision)` | 从 ModelScope 数据集文件创建来源。 |
| `from_encoded_bytes(bytes)`                    | 从编码字节创建来源。       |
| `from_base64(data)`                            | 从 base64 字符串创建来源。 |
| `from_pcm_s16le(bytes, sample_rate, channels)` | 从 PCM S16LE 创建来源。    |
| `new(path_or_url)`                             | 根据是否包含 `://` 推断。  |

优先使用显式的 `from_*()`，避免让调用者猜测 `new()` 的路径/URL 判定规则。

## AudioSource::load / stream {id="audio-source-load",tag="methods"}

`load()` 完整解码来源并返回 [`Audio`](#audio)；`stream(chunk_size_ms)` 只探测
来源，返回随迭代增长的 [`AudioStream`](#audio-stream)。

> #### Example
>
> ```rust
> use asr_data::AudioSource;
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let source = AudioSource::from_url(URL);
>     let mut audio = source.load_with_id("example-001")?;
>     let waveform = audio.as_waveform()?.to_mono()?.resample(16_000)?;
>     println!("{} Hz, {} channel", waveform.sample_rate, waveform.channels);
>     Ok(())
> }
> ```

| Method                                  | Returns                               | Description              |
| --------------------------------------- | ------------------------------------- | ------------------------ |
| `load()`                                | `anyhow::Result<Audio>`               | 完整加载并自动生成 ID。  |
| `load_with_id(id)`                      | `anyhow::Result<Audio>`               | 完整加载并指定文档 ID。  |
| `stream(chunk_size_ms)`                 | `anyhow::Result<AudioStream>`         | 创建流并自动生成 ID。    |
| `stream_with_id(id, chunk_size_ms)`     | `anyhow::Result<AudioStream>`         | 创建流并指定文档 ID。    |

异步完整加载使用 `source.aload().await`。Rust 的 `AudioStream` 实现标准
`Iterator`；需要异步调度时可以在调用侧放入阻塞任务。

## AudioSource::probe {id="audio-source-probe",tag="method"}

读取来源的格式和时长信息，但不解码采样数据。异步环境使用
`source.aprobe().await`。

> #### Example
>
> ```rust
> use asr_data::AudioSource;
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> anyhow::Result<()> {
>     let info = AudioSource::from_url(URL).probe()?;
>     println!("{} Hz, {} ch, {:.2} ms",
>         info.sample_rate, info.channels, info.duration_ms());
>     Ok(())
> }
> ```

| Name        | Description                                  |
| ----------- | -------------------------------------------- |
| `&self`     | 借用来源。                                   |
| **RETURNS** | 音频元信息。~~anyhow::Result&lt;AudioInfo&gt;~~ |

## Waveform transformations {id="waveform-transformations",tag="methods"}

变换方法借用 `&self` 并返回新的 `Waveform`，不会原地修改样本。

> #### Example
>
> ```rust
> use asr_data::Waveform;
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let audio = Waveform::from_url(URL)?;
>     let mono = audio.to_mono()?;
>     let resampled = mono.resample(16_000)?;
>     let clip = resampled.slice_ms(0, 1_000);
>     let parts = resampled.split_at_low_energy(10_000)?;
>
>     println!("{} samples", clip.samples.len());
>     println!("{} parts", parts.len());
>     Ok(())
> }
> ```

| Method                              | Returns                          | Description           |
| ----------------------------------- | -------------------------------- | --------------------- |
| `to_mono()`                         | `Result<Waveform, AudioError>`      | 混合为单声道。        |
| `channel(index)`                    | `Result<Waveform, AudioError>`      | 提取指定声道。        |
| `resample(sample_rate)`             | `anyhow::Result<Waveform>`          | 重采样。              |
| `peak_normalize()` / `with_peak_normalize()` | `()` / `Waveform`            | 峰值缩放到 `[-1, 1]`。 |
| `slice_ms(start_ms, end_ms)`        | `Waveform`                          | 按毫秒截取。          |
| `split_at_low_energy(max_duration_ms)` | `Result<Vec<Waveform>, AudioError>` | 低能量拆分。          |
| `to_i16_pcm()`                      | `Vec<i16>`                       | 转换为 PCM i16 样本。 |

## Waveform::chunk {id="waveform-chunks",tag="method"}

按固定时长把 `Waveform` 切成 `AudioChunk` 列表。切分按帧对齐，最后一块不补零，原波形不会被消耗。

> #### Example
>
> ```rust
> use asr_data::Waveform;
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let audio = Waveform::from_url(URL)?;
>     for chunk in audio.chunk(100)? {
>         println!("{} ms, final={}", chunk.offset_ms, chunk.is_final);
>     }
>     Ok(())
> }
> ```

| Name            | Description                                             |
| --------------- | ------------------------------------------------------- |
| `self`          | 当前 `Waveform`。                                      |
| `chunk_size_ms` | 每块目标时长，必须大于零。~~u64~~                       |
| **RETURNS**     | 音频块列表。~~Result&lt;Vec&lt;AudioChunk&gt;, AudioError&gt;~~ |

## 音频格式类型 {id="audio-types",tag="types"}

`AudioChannel` 用 `Mono`、`Left`、`Right` 或 `Channel(u16)` 表示文档时间轴的规范
声道。`AudioEncoding` 表示来源编码，支持 `Wav`、`Flac`、`Mp3`、
`Ogg`、`PcmS16Le`、`Other(String)` 和 `Unknown`。

`AudioFormat` 保留解码前的格式信息：

| Field         | Type            | Description  |
| ------------- | --------------- | ------------ |
| `encoding`    | `AudioEncoding` | 音频编码。   |
| `sample_rate` | `u32`           | 原始采样率。 |
| `channels`    | `u16`           | 原始声道数。 |

`AudioFormat::pcm16_mono(sample_rate)` 可便捷创建单声道 PCM S16LE 格式。

## AudioInfo {id="audio-info",tag="struct"}

不含采样数组的音频元信息。

| Field           | Type          | Description               |
| --------------- | ------------- | ------------------------- |
| `sample_rate`   | `u32`         | 原始采样率。              |
| `channels`      | `u16`         | 原始声道数。              |
| `frame_count`   | `u64`         | 每个声道的有效采样帧数。  |
| `source_format` | `AudioFormat` | 原始音频格式。            |

`duration_ms()` 返回浮点毫秒，`timeline_duration_ms()` 返回向上取整后的 `usize` 毫秒。

## Audio {id="audio",tag="struct"}

完整音频、时间轴与标注的中心对象，拥有 [`AudioSource`](#audio-source)、
[`AudioInfo`](#audio-info)、各声道 [`Timeline`](#timeline)、业务 metadata 和完整
运行时 [`Waveform`](#waveform)。序列化和数据库持久化会跳过波形。

| Field        | Description                                           |
| ------------ | ----------------------------------------------------- |
| `id`         | 文档 ID。~~String~~                                   |
| `source`     | 原始音频来源。~~AudioSource~~                         |
| `info` | 已探测并持久化的音频信息。~~AudioInfo~~               |
| `metadata`   | 有序 JSON metadata。~~BTreeMap&lt;String, Value&gt;~~ |

timeline 字段通过方法访问，以维持声道、duration 和 audio ID 约束。

| Method | Returns | Description |
| --- | --- | --- |
| `as_waveform()` | `anyhow::Result<Waveform>` | 返回完整波形副本。 |
| `waveform_for_channel(channel)` | `anyhow::Result<Waveform>` | 返回指定声道波形。 |

## Audio::with_id {id="audio-with-id",tag="associated function"}

使用给定 ID 和来源创建记录。构造时探测来源并自动创建各声道 timeline；需要自动 ID
时使用 `Audio::new(source)`。

> #### Example
>
> ```rust
> use asr_data::{Audio, AudioSource};
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> anyhow::Result<()> {
>     let doc = Audio::with_id(
>         "example-001",
>         AudioSource::from_url(URL),
>     )?;
>     println!("{}", doc.id);
>     println!("{:.2} ms", doc.info.duration_ms());
>     Ok(())
> }
> ```

| Name        | Description                                                     |
| ----------- | --------------------------------------------------------------- |
| `audio_id`  | 可转换为 `String` 的记录 ID。~~impl Into&lt;String&gt;~~        |
| `source`    | 可转换为 `AudioSource` 的来源。~~impl Into&lt;AudioSource&gt;~~ |
| **RETURNS** | 新音频记录。~~anyhow::Result&lt;Audio&gt;~~                    |

通常使用 `source.load_with_id(...)` 创建完整音频。`Audio::with_id(...)` 是较底层的
探测式构造函数，波形会在第一次调用 `as_waveform()` 时解码。

## AudioStream {id="audio-stream",tag="struct"}

由 [`AudioSource::stream()`](#audio-source-load) 创建的增长中音频文档，与
[`Audio`](#audio) 同级。它拥有相同的 ID、来源、音频信息、metadata 和各声道
timeline，但波形与 timeline 只覆盖已经迭代出的范围。

也可以直接使用 `AudioStream::from_path(...)`、`from_url(...)`、
`from_modelscope(...)`、`from_encoded_bytes(...)`、`from_base64(...)` 或
`from_pcm_s16le(...)` 创建；`chunk_size_ms` 是流的分块时长。

每次 `next()` 返回 chunk 之前，chunk 样本已经追加到累计波形，各 timeline 也已经
扩展到该 chunk 的结束位置。因此处理当前 chunk 时，可以读取累计波形并修改任意
已接收历史范围的标注。

> #### Example
>
> ```rust
> use asr_data::{AudioChannel, AudioStream};
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> anyhow::Result<()> {
>     let mut stream = AudioStream::from_url(URL, 1_000)?;
>
>     while let Some(chunk) = stream.next() {
>         let chunk = chunk?;
>         let timeline = stream.timeline(AudioChannel::Mono)?.unwrap();
>         println!("{}..{} ms / {} ms",
>             chunk.offset_ms,
>             stream.position_ms(),
>             timeline.duration_ms(),
>         );
>     }
>
>     let audio = stream.into_audio()?;
>     println!("{} frames", audio.info.frame_count);
>     Ok(())
> }
> ```

| Method | Returns | Description |
| --- | --- | --- |
| `timeline(channel)` | `Result<Option<&Timeline>, _>` | 查询增长中的声道时间轴。 |
| `timeline_mut(channel)` | `Result<Option<&mut Timeline>, _>` | 修改已接收范围内的标注。 |
| `as_waveform()` | `Waveform` | 返回累计波形副本。 |
| `position_ms()` | `u64` | 当前已接收结束位置。 |
| `is_complete()` | `bool` | 是否已迭代到来源结尾。 |
| `is_closed()` | `bool` | 是否已提前关闭。 |
| `close()` | `()` | 停止继续迭代。 |
| `into_audio()` | `anyhow::Result<Audio>` | 完整消费后复用全部状态转换为 `Audio`。 |

`into_audio()` 不会重新读取或解码来源，并保留累计波形、timeline、标注和 metadata；
未完整消费或已提前关闭的流不能转换。

## Timeline {id="timeline",tag="struct"}

| Field        | Description                                       |

| `duration`   | 总时长，单位毫秒。~~usize~~                        |
| `reference`  | 不带 source 的参考事件。~~Vec&lt;AudioEvent&gt;~~  |
| `prediction` | 带 source 的预测事件。~~Vec&lt;AudioEvent&gt;~~    |

## Timeline::annotate {id="timeline-annotate",tag="method"}

Timeline 的标注写入口。默认写入 reference（相当于 `is_reference=true` 且不带
`source`）。写入 prediction 时使用 [`annotate_with`](#timeline-annotate-with)，传入
`is_reference=false` 和非空 `source`。`event` 接受 [`AudioEvent`](#audio-event) 或派生

>         0,

## Timeline query methods {id="timeline-query",tag="methods"}

查询、组合转写与管理 prediction source。

> #### Example
>
> ```rust
> use asr_data::{Speech, Timeline, TimelineEventError, Transcription};
>
> fn main() -> Result<(), TimelineEventError> {
>     let duration = 4_205;
>     let mut timeline = Timeline::new("example-001", duration);
>     let speech = Speech::new().with_transcription(
>         Transcription::new("甚至出现交易几乎停滞的情况"),
>     );
>     timeline.annotate(0, duration, speech.clone())?;
>     timeline.annotate_with(0, duration, speech, false, Some("qwen-asr"))?;
>
>     assert_eq!(timeline.span_count(), 2);
>     assert_eq!(
>         timeline.reference_transcript().text,
>         "甚至出现交易几乎停滞的情况"
>     );
>     assert_eq!(
>         timeline.predictions_by_source("qwen-asr").count(),
>         1
>     );
>     timeline.relabel_prediction_source("qwen-asr", "qwen3-asr")?;
>     assert_eq!(timeline.remove_predictions_by_source("qwen3-asr"), 1);
>     Ok(())
> }
> ```

| Method                                 | Returns                                  | Description              |
| -------------------------------------- | ---------------------------------------- | ------------------------ |
| `all_spans()`                          | `impl Iterator<Item = &AudioEvent>`      | 遍历两个集合。           |
| `duration_ms()`                        | `usize`                                  | 总时长毫秒。             |
| `span_count()`                         | `usize`                                  | 事件总数。               |
| `predictions_by_source(source)`        | `impl Iterator<Item = &AudioEvent>`      | 查询某个预测来源。       |
| `prediction_sources()`                 | `BTreeMap<&str, Vec<&str>>`              | 按类型分组的来源。       |
| `transcription_sources()`              | `BTreeSet<String>`                       | 出现过的转写来源。       |
| `activity_sources()`                   | `BTreeSet<String>`                       | 出现过的活动来源。       |
| `reference_transcript()`               | `Transcript`                             | 组合参考转写。           |
| `prediction_transcript(source)`        | `Transcript`                             | 组合指定来源的预测转写。 |
| `remove_event(id)`                     | `bool`                                   | 按 ID 删除事件。         |
| `remove_predictions_by_source(source)` | `usize`                                  | 删除来源并返回数量。     |
| `relabel_prediction_source(from, to)`  | `Result<usize, TimelineEventError>`      | 原子重命名来源。         |
| `validate_spans()`                     | `Result<(), TimelineEventError>`         | 校验全部事件。           |

`reference_transcript()` / `prediction_transcript()` 按语音起点合并各 [`Speech`](#speech)
的 [`Transcription`](#transcription) 全文，并把其中的 [`Sentence`](#sentence) 收集为
`segments`；语种取第一段带转写且标了语种的语音。

## Timeline::eval {id="evaluation",tag="method"}

按照 reference 评测一个或多个 prediction source。空的 `TimelineEvalConfig::new()` 会
自动发现全部可评测转写与 Activity 来源；显式 builder 只启用请求的任务。

> #### Example
>
> ```rust
> use asr_data::{
>     Timeline, TimelineEvalConfig, TimelineEvalError,
>     TranscriptionNormalization,
> };
>
> fn evaluate(timeline: &Timeline) -> Result<(), TimelineEvalError> {
>     let all = timeline.eval(&TimelineEvalConfig::new())?;
>     println!("{}", all.transcription["qwen-asr"].stats.cer());
>
>     let selected = TimelineEvalConfig::new()
>         .with_transcriptions(["qwen-asr", "whisper"])
>         .with_activity("silero-vad")
>         .with_transcription_normalization(
>             TranscriptionNormalization::None,
>         );
>     let result = timeline.eval(&selected)?;
>     println!("{}", result.activity["silero-vad"].f1());
>     println!(
>         "{}",
>         result.activity["silero-vad"].events["speech"].f1()
>     );
>     Ok(())
> }
> ```

| Config method                              | Description                        |
| ------------------------------------------ | ---------------------------------- |
| `with_transcription(source)`               | 评测一个转写来源。                 |
| `with_transcriptions(sources)`             | 评测多个转写来源。                 |
| `with_all_transcriptions()`                | 自动发现全部转写来源。             |
| `with_activity(source)`                    | 评测一个 Activity 来源。           |
| `with_activity_sources(sources)`           | 评测多个 Activity 来源。           |
| `with_all_activity()`                      | 自动发现全部 Activity 来源。       |
| `with_transcription_normalization(value)`  | 选择中文 TN 或不做标准化。         |

`TimelineEvaluation.transcription` 和 `activity` 都是
`BTreeMap<String, ...Evaluation>`。转写自动发现来自带 transcription 的
[`Speech`](#speech)；Activity 覆盖全部 [`AudioEvent`](#audio-event)，语音计入
`speech` 事件。Activity reference 为空时视为未标注，不参与自动评测。
`ActivityEvaluation.events` 进一步按事件名（语音为 `speech`）保存 one-vs-rest 结果。

## 数据集评测 {id="dataset-evaluation",tag="functions"}

`evaluate_dataset()` 聚合任意 Audio 迭代器。需要边读取边处理时可使用
`DatasetEvaluator::new(config)`、`push(&doc)` 和 `finish()`。

> #### Example
>
> ```rust
> use asr_data::{
>     Audio, DatasetEvalError, TimelineEvalConfig,
>     evaluate_dataset,
> };
>
> fn evaluate(docs: &[Audio]) -> Result<(), DatasetEvalError> {
>     let config = TimelineEvalConfig::new();
>     let result = evaluate_dataset(docs.iter(), &config)?;
>     println!("{}", result.transcription["qwen-asr"].cer());
>     println!("{}", result.transcription["qwen-asr"].coverage());
>     Ok(())
> }
> ```

`DatasetEvaluation` 按 source 保存 `DatasetTranscriptionEvaluation` 和
`DatasetActivityEvaluation`。前者累加各 timeline 的 CER 原始计数，后者累加整体
活动与各 event 的 TP、TN、FP、FN 毫秒数；两者都记录参与评测、未标注、缺少预测
的 timeline 数量和 ID，以及 `coverage()`。

## AudioEvent {id="audio-event",tag="enum"}

时间轴上的一条音频事件。`AudioEvent` 是 enum：基类 `Base` 表示音乐、噪声、静音等
非语音事件，`name` 不能为空、也不能是 `speech`；派生变体 `Speech` 表示一段语音，
见 [`Speech`](#speech)。两种值都能直接传给 [`Timeline::annotate`](#timeline-annotate)。
`id`、`range` 和 `source` 由时间轴在写入时覆盖；置信度保存在事件自身，可通过
`confidence()` 读取。

| Variant | Description |
| ------- | ----------- |
| `Base { id, range, source, name, confidence }` | 基类非语音事件。 |
| `Speech(Speech)` | 语音事件，详见 [`Speech`](#speech)。 |

| Method | Returns | Description |
| --- | --- | --- |
| `new(name)` | `AudioEvent` | 构造还没有身份的基类事件。 |
| `with_confidence(confidence)` | `AudioEvent` | 附上检测置信度。 |
| `id()` | `&str` | 事件 ID；尚未写入时为空串。 |
| `range()` | `TimeRange` | 事件覆盖的绝对时间。 |
| `source()` | `Option<&str>` | 预测来源；参考事件为 `None`。 |
| `name()` | `&str` | 事件名；语音固定为 `"speech"`（`SPEECH_EVENT_NAME`）。 |
| `confidence()` | `Option<f32>` | 事件自身的检测置信度。 |
| `language()` | `Option<&str>` | 语音语种；基类事件为 `None`。 |
| `speaker()` | `Option<&Speaker>` | 语音说话人；基类事件为 `None`。 |
| `transcription()` | `Option<&Transcription>` | 语音转写；基类事件为 `None`。 |
| `is_speech()` | `bool` | 是否为派生的 `Speech`。 |
| `content_eq(&other)` | `bool` | 比较业务内容并忽略自动生成的 ID。 |

`impl From<Speech> for AudioEvent` 让语音可以直接传入写入接口。

## Speech {id="speech",tag="struct"}

从 [`AudioEvent`](#audio-event) 派生的语音事件，事件名固定为
`SPEECH_EVENT_NAME`（`"speech"`）。语种、说话人和转写都可以空着，所以只有活动区间
的 VAD 结果也是一条合法语音。`id`、`range` 和 `source` 由时间轴在写入时覆盖。

> #### Example
>
> ```rust
> use asr_data::{AudioEvent, Speech, Speaker, Transcription};
>
> fn main() {
>     let speech = Speech::new()
>         .with_confidence(0.98)
>         .with_language("zh")
>         .with_speaker(Speaker::new("agent"))
>         .with_transcription(Transcription::new("甚至出现交易几乎停滞的情况"));
>     assert_eq!(speech.language.as_deref(), Some("zh"));
>     assert_eq!(speech.confidence, Some(0.98));
>
>     let event = AudioEvent::from(speech);
>     assert_eq!(event.name(), "speech");
>     assert!(event.is_speech());
> }
> ```

| Field           | Description                                            |
| --------------- | ------------------------------------------------------ |
| `id`            | 写入时生成的事件 ID。~~EventId~~                       |
| `range`         | 语音在时间轴上的绝对时间。~~TimeRange~~                |
| `source`        | 预测来源；参考事件为 `None`。~~Option&lt;String&gt;~~  |
| `confidence`    | 可选活动检测置信度。~~Option&lt;f32&gt;~~              |
| `language`      | 可选 BCP-47 语种标签。~~Option&lt;LanguageTag&gt;~~    |
| `speaker`       | 这段语音的唯一说话人。~~Option&lt;Speaker&gt;~~        |
| `transcription` | 这段语音的转写。~~Option&lt;Transcription&gt;~~        |

| Method | Description |
| --- | --- |
| `new()` | 构造还没有身份的语音。 |
| `with_confidence(confidence)` | 附上活动检测置信度。 |
| `with_language(language)` | 附上语种。~~impl Into&lt;LanguageTag&gt;~~ |
| `with_speaker(speaker)` | 附上说话人；一段语音只有一个。 |
| `with_transcription(transcription)` | 附上转写。 |

相同事件名的非语音事件不能在同一 reference 集合或同一 prediction source 中重叠；
语音只有在双方都有说话人、且姓名不同时才可以重叠。

| Field          | Description                                   |
| -------------- | --------------------------------------------- |
| `kind`         | 冲突类别。~~EventConflictKind~~               |
| `source`       | 冲突事件的预测来源。~~Option&lt;String&gt;~~  |
| `speaker`      | 涉及冲突的说话人。~~Option&lt;String&gt;~~    |
| `first_id`     | 先写入的事件 ID。~~EventId~~                  |
| `first_range`  | 先写入事件的时间范围。~~TimeRange~~           |

## Transcription {id="transcription",tag="struct"}

一段语音里的转写。全文 `text` 是最小内容，单独存在即可；句级 [`Sentence`](#sentence)
切分可以为空。`Transcription::new(text)` 提供合理默认值，再按需修改公开字段是
Rust 中最直接的构造方式。

> #### Example
>
> ```rust
> use asr_data::{Sentence, Token, Transcription};
>
> fn main() {
>     let sentence = Sentence::new("甚至出现交易几乎停滞的情况", 0, 4_205)
>         .with_tokens(vec![
>             Token::new("甚至出现").with_range(0, 1_800),
>             Token::new("交易几乎停滞的情况").with_range(1_800, 4_205),
>         ]);
>     let transcription = Transcription::new(
>         "甚至出现交易几乎停滞的情况",
>     )
>     .with_sentences(vec![sentence])
>     .with_confidence(0.93);
>
>     println!("{}", transcription.text);
> }
> ```

| Field        | Description                                    |
| ------------ | ---------------------------------------------- |
| `text`       | 整段转写文本。~~String~~                       |
| `sentences`  | 句级切分。~~Vec&lt;Sentence&gt;~~              |
| `confidence` | 可选整段置信度。~~Option&lt;f32&gt;~~          |

| Method | Description |
| --- | --- |
| `new(text)` | 用整段文本构造转写；句子和置信度留空。 |
| `with_sentences(sentences)` | 附上句级切分；空列表等于不切分。 |
| `with_confidence(confidence)` | 附上整段置信度。 |

## Sentence {id="sentence",tag="struct"}

一句转写。时间是时间轴上的绝对毫秒，并且必须落在所属语音区间内。

> #### Example
>
> ```rust
> use asr_data::{
>     Sentence, Speech, Timeline, TimelineEventError, Token, Transcription,
> };
>
> fn main() -> Result<(), TimelineEventError> {
>     let sentence = Sentence::new("甚至出现交易几乎停滞的情况", 0, 4_205)
>         .with_tokens(vec![Token::new("甚至出现").with_range(0, 1_800)]);
>     let speech = Speech::new().with_transcription(
>         Transcription::new("甚至出现交易几乎停滞的情况")
>             .with_sentences(vec![sentence]),
>     );
>
>     let mut timeline = Timeline::new("example-001", 4_205);
>     timeline.annotate(0, 4_205, speech)?;
>     assert_eq!(
>         timeline.reference_transcript().text,
>         "甚至出现交易几乎停滞的情况"
>     );
>     Ok(())
> }
> ```

| Field    | Description                                |
| -------- | ------------------------------------------ |
| `text`   | 整句文本。~~String~~                       |
| `range`  | 这句覆盖的绝对时间范围。~~TimeRange~~      |
| `tokens` | 词级 token，可以为空。~~Vec&lt;Token&gt;~~ |

| Method | Description |
| --- | --- |
| `new(text, start_ms, end_ms)` | 用文本和绝对时间构造句子，token 列表为空。 |
| `with_tokens(tokens)` | 附上词级 token。 |

非空句子的时间必须落在所属语音区间内且互不重叠；token 时间必须落在句子内。

## AudioDataset {id="audio-dataset",tag="struct"}

> from asr_data import AudioDB, AudioDataset
>
> train = AudioDB.create("train.db")
> test = AudioDB.create("test.db")
> dataset = AudioDataset(train=train, test=test)
> print(len(dataset.train), dataset.val, len(dataset.test))
> ```

> #### Rust Example
>
> ```rust
> use std::fs;
>
> use asr_data::{read_audio_db_info, AudioDataset, AudioDb};
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let root = std::env::temp_dir();
>     let train_path = root.join("asr-data-train-example.db");
>     let test_path = root.join("asr-data-test-example.db");
>     for path in [&train_path, &test_path] {
>         let _ = fs::remove_file(path);
>     }
>
>     let train = AudioDb::create(&train_path)?;
>     let test = AudioDb::create(&test_path)?;
>     let dataset = AudioDataset::new(
>         Some((train_path.clone(), train)),
>         None,
>         Some((test_path.clone(), test)),
>     );
>     let info = read_audio_db_info(dataset.train_database_path().unwrap())?;
>     println!("{} train records", info.audios);
>
>     drop(dataset);
>     for path in [train_path, test_path] {
>         fs::remove_file(path)?;
>     }
>     Ok(())
> }
> ```

| Method | Returns | Description |
| --- | --- | --- |
| `new(train, val, test)` | `AudioDataset` | 接管零到三个可选 `(PathBuf, AudioDb)`。 |
| `name()` / `version()` / `license()` | `&str` | 读取身份字段。 |
| `train()` / `val()` / `test()` | `Option<&AudioDb>` | 借用存在的切分数据库。 |
| `train_database_path()` / `val_database_path()` / `test_database_path()` | `Option<&Path>` | 读取存在的数据库路径。 |
| `into_databases()` | `(Option<AudioDb>, Option<AudioDb>, Option<AudioDb>)` | 消耗数据集并取出可选数据库。 |

## AudioDataset::from_modelscope {id="audio-dataset-modelscope",tag="associated function"}

调用 modelhub 下载完整仓库，复用默认缓存或显式缓存根目录，并只读打开快照中存在
的 `train.db`、`val.db`、`test.db`；缺失切分为 `None`。name 使用 repo_id，
version 使用 revision，license 读取可选 README front matter。

> #### Example
>
> ```rust
> use asr_data::AudioDataset;
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let dataset = AudioDataset::from_modelscope(
>         "di-osc/aishell-1",
>         Some("v1.0.0"),
>         None,
>     )?;
>
>     if let Some(test) = dataset.test() {
>         let page = test.query(&Default::default())?;
>         println!("{} records in first page", page.len());
>     }
>     Ok(())
> }
> ```

`revision` 为 `None` 时使用 `master`，`cache_dir` 为 `None` 时使用 modelhub
缓存根目录（`MODELHUB_CACHE`，否则 `~/.cache/modelhub`）。快照目录为
`{cache}/datasets/{repo--id}/modelscope/snapshots/{revision}`。

| Name        | Description                                                                  |
| ----------- | ---------------------------------------------------------------------------- |
| `repo_id`   | ModelScope 数据集仓库 ID。~~&str~~                                           |
| `revision`  | 可选 revision。~~Option&lt;&str&gt;~~                                         |
| `cache_dir` | 可选缓存根目录。~~Option&lt;&Path&gt;~~                                       |
| **RETURNS** | 数据集或上下文化错误。~~Result&lt;AudioDataset, AudioDatasetError&gt;~~       |

## AudioDb {id="audio-db",tag="struct"}

SQLite 数据库句柄。写操作借用句柄；仅 `update_many()` 因事务需要可变借用。

## AudioDb::create / open {id="audio-db-open",tag="associated functions"}

`create(path)` 只创建新数据库，路径已存在时返回 `AudioDbError::AlreadyExists`。
`open(path, mode)` 只打开已有数据库，路径不存在时返回
`AudioDbError::DatabaseNotFound`。

> #### Example
>
> ```rust
> use std::fs;
>
> use asr_data::{AudioDb, AudioDbMode};
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let path = std::env::temp_dir().join("asr-data-open-example.db");
>     let _ = fs::remove_file(&path);
>
>     let db = AudioDb::create(&path)?;
>     println!("schema {}", AudioDb::SCHEMA_VERSION);
>     drop(db);
>
>     let readonly = AudioDb::open(&path, AudioDbMode::ReadOnly)?;
>     drop(readonly);
>     fs::remove_file(path)?;
>     Ok(())
> }
> ```

| Method             | Description                                         |
| ------------------ | --------------------------------------------------- |
| `create(path)`     | 创建新数据库。~~Result&lt;AudioDb, AudioDbError&gt;~~ |
| `open(path, mode)` | 打开已有数据库。~~Result&lt;AudioDb, AudioDbError&gt;~~ |
| `from_modelscope(repo_id, file_path, revision, cache_dir)` | 下载数据集中的一个数据库文件并只读打开。 |

## AudioDb CRUD {id="audio-db-crud",tag="methods"}

> #### Example
>
> ```rust
> use std::fs;
>
> use asr_data::{
>     AudioDb, AudioDbMode, Audio, AudioSource,
> };
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let path = std::env::temp_dir().join("asr-data-crud-example.db");
>     let _ = fs::remove_file(&path);
>     let db = AudioDb::create(&path)?;
>
>     let doc = Audio::with_id("example-001", AudioSource::from_url(URL))?;
>     db.insert(&doc)?;
>     let loaded = db.get("example-001")?.expect("inserted audio");
>     println!("{}", loaded.id);
>     assert!(db.contains("example-001")?);
>     assert!(db.delete("example-001")?);
>
>     drop(db);
>     fs::remove_file(path)?;
>     Ok(())
> }
> ```

| Method                 | Returns                                  | Description          |
| ---------------------- | ---------------------------------------- | -------------------- |
| `insert(&audio)`       | `Result<(), AudioDbError>`               | 插入新记录。         |
| `get(audio_id)`        | `Result<Option<Audio>, AudioDbError>` | 按 ID 查询。         |
| `contains(audio_id)`   | `Result<bool, AudioDbError>`             | 判断是否存在。       |
| `update(&audio)`       | `Result<bool, AudioDbError>`             | 仅在内容变化时更新。 |
| `update_many(&audios)` | `Result<usize, AudioDbError>`            | 在事务中批量更新。   |
| `delete(audio_id)`     | `Result<bool, AudioDbError>`             | 删除记录。           |

## AudioDb metadata {id="audio-db-metadata",tag="methods"}

数据库级键值 metadata，与单条 `Audio.metadata` 相互独立。

> #### Example
>
> ```rust
> use std::fs;
>
> use asr_data::AudioDb;
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let path = std::env::temp_dir().join("asr-data-metadata-example.db");
>     let _ = fs::remove_file(&path);
>     let db = AudioDb::create(&path)?;
>
>     db.set_metadata("dataset", &serde_json::json!("calls"))?;
>     assert_eq!(
>         db.metadata("dataset")?,
>         Some(serde_json::json!("calls"))
>     );
>     assert!(db.delete_metadata("dataset")?);
>
>     drop(db);
>     fs::remove_file(path)?;
>     Ok(())
> }
> ```

此示例需要在 `Cargo.toml` 中同时依赖 `serde_json`。

| Method                      | Returns                                         | Description           |
| --------------------------- | ----------------------------------------------- | --------------------- |
| `set_metadata(key, &value)` | `Result<(), AudioDbError>`                      | 设置数据库 metadata。 |
| `metadata(key)`             | `Result<Option<Value>, AudioDbError>`           | 读取单个值。          |
| `all_metadata()`            | `Result<BTreeMap<String, Value>, AudioDbError>` | 读取全部值。          |
| `delete_metadata(key)`      | `Result<bool, AudioDbError>`                    | 删除值。              |

`read_audio_db_info(path)` 可以不加载文档内容就读取数据库概况，返回
`AudioDbInfo { schema_version, audios, total_duration }`。

## AudioQuery {id="audio-query",tag="struct"}

数据库查询参数。通常从 `AudioQuery::default()` 开始，只覆盖所需字段。

> #### Example
>
> ```rust
> use std::fs;
> use std::time::{Duration, SystemTime};
>
> use asr_data::{
>     AudioDb, AudioDbMode, Audio, AudioQuery, AudioSource,
> };
>
> const URL: &str =
>     "https://deepasset.oss-cn-beijing.aliyuncs.com/example.wav";
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let path = std::env::temp_dir().join("asr-data-query-example.db");
>     let _ = fs::remove_file(&path);
>     let db = AudioDb::create(&path)?;
>
>     let mut doc = Audio::with_id("example-001", AudioSource::from_url(URL))?;
>     doc.metadata.insert("split".into(), serde_json::json!("train"));
>     db.insert(&doc)?;
>
>     let mut query = AudioQuery::default();
>     query.limit = 100;
>     query.created_from = Some(SystemTime::now() - Duration::from_secs(7 * 24 * 60 * 60));
>     query.updated_from = Some(SystemTime::now() - Duration::from_secs(24 * 60 * 60));
>     query.metadata.insert("split".into(), serde_json::json!("train"));
>     let page = db.query(&query)?;
>     println!("{} result", page.len());
>
>     drop(db);
>     fs::remove_file(path)?;
>     Ok(())
> }
> ```

此示例需要在 `Cargo.toml` 中同时依赖 `serde_json`。

| Field           | Description                                            |
| --------------- | ------------------------------------------------------ |
| `limit`         | 最大返回数，默认 `DEFAULT_QUERY_LIMIT`。~~usize~~      |
| `after`         | 上一页最后一个 audio ID。~~Option&lt;String&gt;~~      |
| `min_duration`  | 可选最短时长，单位毫秒。~~Option&lt;usize&gt;~~             |
| `max_duration`  | 可选最长时长，单位毫秒。~~Option&lt;usize&gt;~~             |
| `created_from`  | 创建时间下界，包含。~~Option&lt;SystemTime&gt;~~       |
| `created_until` | 创建时间上界，不包含。~~Option&lt;SystemTime&gt;~~     |
| `updated_from`  | 修改时间下界，包含。~~Option&lt;SystemTime&gt;~~       |
| `updated_until` | 修改时间上界，不包含。~~Option&lt;SystemTime&gt;~~     |
| `metadata`      | 精确匹配的 metadata。~~BTreeMap&lt;String, Value&gt;~~ |

`AudioDb::eval(&query, &config)` 使用同一组筛选条件，并自动用 `query.limit` 作为每
批读取数量遍历全部匹配文档：

> #### Example
>
> ```rust
> use asr_data::{
>     AudioDb, AudioQuery, DatasetEvalError, TimelineEvalConfig,
> };
>
> fn evaluate(
>     db: &AudioDb,
>     query: &AudioQuery,
> ) -> Result<(), DatasetEvalError> {
>     let result = db.eval(
>         query,
>         &TimelineEvalConfig::new().with_transcription("qwen-asr"),
>     )?;
>     println!("{}", result.transcription["qwen-asr"].cer());
>     Ok(())
> }
> ```

`limit` 不得超过 `MAX_QUERY_LIMIT`（10,000），且时长或时间范围的下界不得大于上界
。创建和修改时间由数据库自动维护，不会写入 `Audio`。

`TimelineEvalConfig` 还提供
`with_traditional_to_simple()`、`with_full_to_half()`、`with_remove_erhua()`、
`with_remove_interjections()` 和 `with_remove_puncts()`，用于统一配置 reference 与
prediction 的中文归一化。只需说话人指标时，可以调用
`AudioDb::eval_speaker(&query, &sources)`；结果为 `DatasetSpeakerEvaluation`，
逐 timeline 做标签无关的最优说话人映射后计算 DER。当前不使用 collar，重叠语音按
speaker-time 计数。

## 时间类型 {id="time-types",tag="structs"}

整数毫秒使用 `usize`。半开区间用 `TimeRange` 表示。

| Type                             | Description                                              |
| -------------------------------- | -------------------------------------------------------- |
| `TimeRange { start_ms, end_ms }` | 半开时间范围 `[start_ms, end_ms)`，单位毫秒，端点为 `usize`。 |

`TimeRange::duration()` 返回饱和相减后的时长；`overlaps(&other)` 判断范围重叠；
`contains(point_ms)` 使用 `start_ms <= point_ms < end_ms`。

## 中文文本归一化 {id="normalize-zh",tag="function"}

`normalize_zh()` 使用内嵌的中文 TN FST，把书写形式转换为口语形式。资源随 crate
一起编译，不需要安装或调用外部服务。

> #### Example
>
> ```rust
> use asr_data::normalize_zh;
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let text = normalize_zh("2024年")?;
>     assert_eq!(text, "二零二四年");
>     Ok(())
> }
> ```

| Name        | Description                                                  |
| ----------- | ------------------------------------------------------------ |
| `text`      | 需要归一化的文本。~~&str~~                                   |
| **RETURNS** | 归一化结果。~~Result&lt;String, TextNormalizationError&gt;~~ |

需要额外清理时，使用 `normalize_zh_with_options()`：

> #### Example
>
> ```rust
> use asr_data::{
>     normalize_zh_with_options, ChineseTextNormalizationOptions,
> };
>
> fn main() -> Result<(), Box<dyn std::error::Error>> {
>     let options = ChineseTextNormalizationOptions {
>         traditional_to_simple: true,
>         full_to_half: true,
>         remove_erhua: true,
>         remove_interjections: true,
>         remove_puncts: true,
>     };
>     let text = normalize_zh_with_options("嗯，這個花兒！", options)?;
>     println!("{text}");
>     Ok(())
> }
> ```

选项按繁转简、中文 TN、去儿化、全角转半角、去语气词、去标点的顺序执行，默认值均
为 `true`。去语气词覆盖常见的“嗯”“啊”“呃”。

## CER {id="cer",tag="functions"}

计算字符错误率。

> #### Example
>
> ```rust
> use asr_data::{compute_cer, normalize_for_cer};
>
> fn main() {
>     let reference = normalize_for_cer(
>         "甚至出现交易几乎停滞的情况",
>         true,
>     );
>     let hypothesis = normalize_for_cer(
>         "甚至出现交易几乎停止的情况",
>         true,
>     );
>     let stats = compute_cer(&reference, &hypothesis);
>     println!("CER: {:.2}%", stats.cer() * 100.0);
> }
> ```

| Function                                 | Returns    | Description                          |
| ---------------------------------------- | ---------- | ------------------------------------ |
| `normalize_for_cer(text, remove_spaces)` | `String`   | 移除标点，并按参数决定是否移除空白。 |
| `compute_cer(reference, hypothesis)`     | `CerStats` | 计算编辑距离统计。                   |

## 错误类型 {id="errors",tag="enums"}

公共错误均实现 `std::error::Error`，应用层可以使用 `?` 传播或按 enum variant 精
确匹配。

| Type                      | Scope                                      |
| ------------------------- | ------------------------------------------ |
| `AudioError`              | 样本、声道、PCM 和 chunk 校验。            |
| `AudioDatasetError`       | ModelScope 下载、license 和切分数据库校验。 |
| `AudioDbError`            | SQLite、序列化、查询和迁移。               |
| `AudioChannelError`       | 非规范声道。                               |
| `AudioTimelineError`      | timeline duration 创建约束。               |
| `AudioValidationError`    | Audio 完整性校验。                         |
| `TimelineEventError`      | 事件 source、事件名、语音内部时间与重叠冲突。 |
| `TimelineEvalError`       | 单条 timeline 评测配置或执行错误。         |
| `DatasetEvalError`        | 数据集评测聚合错误。                       |
| `TextNormalizationError`  | 中文 TN FST 归一化失败。                   |

`TimelineEventError` 常见 variant 包括 `ReferenceHasSource`、
`PredictionMissingSource`、`InvalidPredictionSource`、`InvalidEventName`、
`SpeechEventName`、`InvalidSpeakerName`、`InvalidSentenceRange`、
`InvalidTokenRange`、`SentenceOutsideSpeech`、`TokenOutsideSentence`、
`OverlappingSentences` 和 `Overlap`（携带 [`EventOverlap`](#event-overlap)）。完整定义
以本地 crate 源码与生成的 rustdoc 为准。
